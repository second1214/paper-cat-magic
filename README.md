# My Cat Is So Cute

（リポジトリ名: paper-cat-magic）

ママは虫が大の苦手。おうちに入りこんだ虫を、猫がおもちゃで追い払う見下ろし型アクション（ブラウザ / three.js）。

**遊ぶ**: https://my-cat-is-so-cute.pages.dev/ （Cloudflare Pages。main に入ると自動で公開）

## 遊び方

タイトル画面から「つづきから／はじめる／あそびかた／ずかん（全部の技・おもちゃの説明）」を選べます。冒険は**部屋に入るたびに自動でセーブ**され、途中でやめても「つづきから」でその部屋の入口から再開できます（やられた・守りきったときにセーブは消える）。いちばん遠くまで進んだ部屋と、守りきった回数はブラウザに記録されます。

秋→冬→春→夏の4季節（虫が一番多い夏が最終章）。各季節はお庭・リビング・寝室・書斎・和室・洋室から選ばれた4部屋（形も家具も毎回変わる）＋スズメバチのボス部屋。

## おもちゃと技のしくみ

猫がおもちゃを振ると、スロットにはめた**技そのもの**が出ます。技ごとに動きが違います。

| 動き | 技 |
|---|---|
| 飛ぶ | ひっかき・かみつき・毛玉（範囲）・シャー（すくませる） |
| まわりを回る | ぶんぶん（ねこじゃらしの先が猫のまわりを回る） |
| ビーム | 毛糸玉ころがし（のびた糸で何度もこする）・レーザーポインター（一瞬で壁まで） |
| 衝撃波 | ねこジャンプ（着地の輪で虫をはじく） |
| 近くを連打 | 猫パンチ連打 |
| 床に置く | 爪とぎ（上を通る虫を削る・4つまで） |
| 召喚 | 友達猫（虫を追いかけてひっかく）・ルンバ（走り回って虫を吸いこむ）。左の修飾・属性は仲間の攻撃にかかる。召喚ごとに呼べる数（友達猫2・ルンバ1。札を何枚つけても同じ）があり、ママのお直しで★にするたび＋1、レリック「ねずみのおもちゃ」で＋1。超えて呼ぶと一番古い仲間が帰る |
おもちゃのスロットは**左から順に**使われ、最後まで使うと少し休けいします。

- **技**（赤い実線の枠）：ひっかき・かみつき・毛玉（範囲）・シャー（すくませて遅くする）
- **修飾**（青い点線の枠）：矢印の向きでかかる技が決まる。
  - ▶ **右の技**：またたび（強化）・かじかじ（多段）・でっかく・ちっちゃく（豆つぶで高威力）・すばやく・じーっ（追尾）・ぽよん（反射）・ぐいぐい（貫通）・二刀流（右の2つを同時に）ほか
  - ◀ **左の技**：おかわり（＋1回当たる）・おいかけっこ（追尾）・つるつるの床（はね返り＋遠くまで）
  - ◀▶ **左右の技**（2つをいっしょに出す）：ドライヤー・またたび袋・こたつ布団
  - **全** 全体修飾（どこに置いても全部の技に。読まれず、やる気の最大が減る）：迷子札・ひだまり・人感センサーライト・毛づくろい
- **つづけて**：`[ひっかき][つづけて][ぶんぶん]` ＝ ひっかきが当たった所を中心にぶんぶんが回る（何段でもつながる）。右が飛ぶ技なら当たった虫を通りこして先の虫へ、置く技は着弾地点に置く、2つ以上なら扇状に出る。**ひと呼吸**は当たらなくても0.45秒後にその場所から。
- **弾を増やす（掛け算）**：二刀流（×2）・ねこ団子（×3）・多頭飼い（×4）は右の技を同時に、カリカリぶちまけは1発を扇状の5発に（重ねると掛け算）、毛糸のほつれは消えるときに3つに割れる。
- **何度も発動するつづけて**：何度でも（当たるたびに）・ぴょんぴょん（はね返るたびに）・とどめ（虫を倒したら）。
- **速さ・やる気**：まっしぐら（振る間隔・休けいを短く）・ちゅ〜る休憩（やる気が戻る）。レリックの自動給餌器（消費−25%）・キャットウォーク（間隔−20%）。
- 重くならないよう、猫の技が同時に出ていられるのは400個まで。後半の季節には、弱い虫が20匹以上で押し寄せる**大群**の波がまざる。
- **ふたつ持ち**：`[A][ふたつ持ち][B]` ＝ 前足でおもちゃを2つ同時に扱い、A と B を1つの技にまとめて出す（攻撃力・多段・貫通・はね返り・範囲・属性を足す）。
- **レア度**：技は ふつう／レア／エピック／伝説（マスの下の帯）。**秘密の隠し場所**（ソファの下・ママのところにもある）に同じレア度の物を4つ押しこむと、奥から前に失くした1つ上のレア度の物がランダムで1つ出てくる。
- **属性**（おうちのもの）：静電気＝ビリビリ（近くの虫へ飛び移る）・水のみ皿＝びしょぬれ（遅くなる）・ガムテープ＝ねばねば（足止め）・虫よけスプレー＝虫よけ（じわじわダメージ）。**ぬれた虫にビリビリは2倍**、**ねばねばの虫に虫よけは2倍**
- スロットの下の線が「1回で一緒に出るまとまり」。⚔はその合計攻撃力、⚡は使うやる気。次に出るまとまりが光ります。
- 技・おもちゃは、攻撃力・やる気・弾の速さ・とどく距離などの数値つきカードで表示されます。

| おもちゃ | 特徴 |
|---|---|
| ねこじゃらし | 8スロット。ふつう |
| トンボじゃらし | 6スロット。トンボが少し虫を追いかける。休けいが短い |
| ティッシュボール | 12スロット。壁で1回はね返る。休けいが長い |
| けりぐるみ | 5スロット。攻撃力×1.35、振るのが遅い |
| ピンポン玉 | 7スロット。速く、2回はね返る |
| ただのひも | 14スロット。休けいが長い |
| ペットボトルのキャップ | 5スロット。やる気の回復がとても速く休けいが短い |
| ロングじゃらし | 9スロット。1.4倍遠くまで届き、少し大きい |
| 鈴入りボール | 全部のスロットを1回でいっぺんに出す |
| ねこじゃらし福袋 | 16スロット。やる気がたっぷり、休けいが長い |
| 紙袋 | サブスロット2：1.5秒じっとすると発動 |

- **電池式のおもちゃ**（持ち替えの3つとは別に2つまで）：持っているだけで、一番近い虫へ自動で振る。電動ねずみ・自動レーザー・ぴちぴち魚（USB充電の動く魚）・電動くるくるじゃらし。中の技は入れ替えられる。

## レリックと装備

- **おもちゃは3つまで持てる**（やる気と次のスロットはおもちゃごとに覚えている）。持ち替えはスロットの左の小さなおもちゃ／Q／1〜3／ホイール。
- **レリック**：最大HP・攻撃力・やる気回復・移動の速さ・召喚の上限・ごほうびの選択肢など。まだ持っていないものが先に出て、そろってくると同じものも出る（5個まで重なる）。重ねると、強くなる倍率は足し算（キャットタワー＋15%×3＝＋45%）、減らす倍率は掛け算、確率は「どれか1つが当たる」。会心60%・もう1発75%・選択肢＋2・消費−60% などの上限あり。持ち物では ×2 のように数が出る。
- **装備**（4セット×頭・服・首）：飼い主が「かわいい！」と買ってきた、よくわからない物を着せられている。1つずつの効果に加え、同じセットを2つ・3つそろえるとボーナス。
  - ハワイのお土産（ハイビスカスの髪飾り・アロハシャツ・フラのレイ）：やる気回復、3つで止まっていると回復2倍
  - ガチャガチャの天使（天使の輪カチューシャ・天使の羽・光るハートの首輪）：当たりを防ぐ、3つで部屋を片付けるとHP15回復
  - くだものの被り物（みかんの被り物・スイカ柄のTシャツ・さくらんぼの首輪）：最大HP、3つで当たったあとのむてき＋0.5秒
  - ママの手編み（毛糸の帽子・手編みのセーター・迷子札の首輪）：攻撃力、3つでダッシュのあと攻撃力1.5倍
- **買ってきた物の技・修飾**（12種）：水鉄砲（びしょぬれ）・ゴムのアヒル（はね返る）・シャボン玉（漂って追いかける）・ハロウィンのかぼちゃ（大きくはじける）・粘着コロコロ（線の上の虫がくっつく）・ピコピコハンマー・自撮りフラッシュ（まわりをすくませる）・通販の段ボール（床に置く）／ラメのシール・鈴のリボン・よくわからない健康グッズ・自撮り棒
- 「持ち物」画面のタブで、おもちゃごとのスロットと、装備・レリックを確認できます。

## ステージ・お店・さいご

- 部屋は 28×16 マスに広くなり、カメラが猫を追う。各季節は8部屋＋ボス（章の真ん中に必ずお店の扉、ときどき特別な部屋の扉）。部屋は お庭／池のあるお庭／家庭菜園（外）、リビング・寝室・書斎・和室・洋室・キッチン・お風呂場・玄関（家の中）。毎章どこかで外を通る。
- 虫を倒すと **カリカリ**（お金）が落ちる。👩の扉の先は **ママのところ**（拾ったカリカリと交換で技やおやつをおねだり・「ほかのも見せて」〔だんだん高くなる〕・売ることはできない）。**ママのお直し** では、同じ物3つをママが縫い合わせて丈夫な★の物1つにしてくれる（★★まで）。
- **パパ**：まれにリビングで寝ころんでいる大好きなパパ。お腹の上で2.5秒じっとしているとぐっすり眠れて、最大HP ＋20・やる気の最大 ＋15（全部のおもちゃ、1部屋1回）。ただし3回に1回くらいは強制猫吸いされて失敗（しばらく動けない。ダメージはない）。攻撃は当たらない。絵は `public/papa/{sleep,suck}.png` を置くと差し替わる（ないときは仮の絵）。
- **子どもたち**：まれにリビングへ、お兄ちゃん（6さい）と妹（3さい）が遊びに来る。猫と遊びたくて部屋じゅう追いかけてくるが、猫は必死に逃げる（そばに来ると少し速く走る）。攻撃は効かない（当たらない）。つかまると数秒だっこでもみくちゃにされて動けずHPが減る（ダッシュでじたばたすると早く抜け出せる）。逃げられた子は少し息をととのえて、また追いかけてくる。部屋を片付けたあとも残って追いかけてくるので、扉まで逃げきる。絵は `public/kids/{boy,girl}_{walk,run,hug}.png`（追いかける・ひと息・だっこ）。

## エンドレスモードとランキング

- タイトルの「エンドレス」: 夏のボスのあとも季節がめぐり続け（2年目の秋…）、虫はどんどん強くなる。難易度は「ふつう」固定。
- ポイント: 片付けた部屋×100・ボス×500・強い虫×30・倒した虫×5。遊んでいる間は左上に ★ で表示。
- ランキング: 「じぶん」（この端末の上位10回）と「みんな」（名前を入れて送る・上位50）。
- みんなのランキングは Cloudflare Pages Functions（`functions/api/scores.ts`）と D1 データベースで動く。D1 を `DB` という名前でつなぐまでは「準備中」と出る。名前は12文字まで、連絡先や不適切な言葉ははじく。ありえない記録や30秒以内の連続送信もはじく（IP はそのまま保存せず、日ごとに変わるハッシュだけ）。

## トレーニング部屋

- タイトルの「トレーニング」。的は**エビのけりぐるみ**（動かない・攻撃しない・倒れない。はじいても元の場所に戻る）。

## 強い虫と呪い

- **強い虫**：足元が光る大きな虫。体力3倍（かたいは4.5倍）、カリカリを多く落とす。性質は すばしこい／分かれる（倒すと2匹に）／はじける（倒すと輪の弾）／かたい。季節・部屋が進むほど出やすい。

## 解放（負けても積み上がる）

## 装備のレアリティ・難易度・ねこの成長

- 装備は **ふつう／レア／エピック／伝説**。上がるほど効果が大きく、エピックは1つ・伝説は2つの特殊効果（会心・倒して回復・倒すとはじける・反撃・バリア・もう1発・走ってやる気）がつく。セットは6種（100円ショップ・ペットショップの新作を追加）。
- 特殊効果を持つレリック（きらきらビー玉・ハムスターの回し車・防犯ブザー・ペットのお守り・高級猫缶・ママのコピー用紙）を追加。
- **難易度**：やさしい／ふつう／むずかしい／悪夢（むずかしいを守りきると選べる。虫の攻撃がとても痛い）。
- **HP と虫の攻撃**：HP は数値（ふつうは最初 80）。虫ごとに攻撃力があり（アリ8〜毛虫15、ボス22〜26、弾10）、季節が進むほど痛くなる（夏で約2倍）。エンドレスの2年目からは、虫の攻撃（年に×1.16⁴）と体力（×1.24⁴）が増え続けるので、いつかは必ず負ける。当たったときは赤い数字が出る。
- **ねこの成長**：冒険でもらう「にぼし」（片付けた部屋・倒したボス・クリア×難易度）で永続強化。じょうぶな体（最大HP＋10×10）・とがった爪（攻撃力＋5%×10）・やる気満々（＋10×10）・ごはん大好き（やる気回復＋6%×5）・しなやかな足（＋3%×5）・もふもふの毛（受けるダメージ−4%×8）・招き猫の運・ママのおみやげ（最初からレリック、3つまで）・へそくり（最初のカリカリ＋5×5）・九つの命（1回の冒険に1度、やられてもHP30%で起き上がる）・おきにいりの箱・ひなたぼっこ（攻撃力・最大HP＋1%、上限なし）。
- **おきにいり**：クリアしたとき（ママにつかまった）、持っている技（手持ち・スロット・サブスロット・電池式の中身）から「おきにいり」を選ぶと、次からの冒険で最初から手持ちに入る（★もそのまま。エンドレスでも）。枠ははじめ1つ、ねこの成長「おきにいりの箱」（にぼし30〜120）で最大5つまで増える。次にクリアして選び直すまで同じおきにいりが続く。

## 開発

```sh
npm install
npm run dev     # 開発サーバー（同じ Wi-Fi のスマホからも開ける）
npm test        # 発射ロジック・技の動きと属性・部屋の形・自動プレイ（全季節を通しで詰まないか）のテスト
npm run build   # dist/ に出力
```

- おもちゃ・技のロジック：`src/core/`（DOM 非依存・テストあり）
- ゲームの状態と更新：`src/game/world.ts`、部屋の形と家具配置：`src/game/stage.ts`（描画に依存しない）
- アイテムの絵（3D と UI で共通）：`src/art/items.ts`
- 描画：`src/render/`（three.js。猫は `public/cat/` の紙人形ステッカー、部屋は `roomBuilder.ts`）
- UI・入力：`src/ui/hud.ts`、`src/input.ts`

`main` に push すると GitHub Pages に自動公開されます。

### CrazyGames 版

```sh
npm run build:crazy   # dist-crazygames/ と、アップロード用の my-cat-crazygames.zip を作る
```

- CrazyGames SDK v3 を読み込み、読み込み・遊んでいる最中（gameplayStart/Stop）・うれしい瞬間（ボス撃破・クリア）を伝える。保存は SDK の保存（アカウントに同期）を使う
- ごほうび広告: やられたときに1回だけその場で復活／結果画面でにぼし2倍。ふつうの Web 版には出ない
- みんなのランキングは `https://my-cat-is-so-cute.pages.dev/api/scores` を呼ぶ（`.env.crazygames`。API は CORS 対応）
- 共通の切り替えは `src/platform/`

### ことば（日本語／英語）

ブラウザの言語で自動で切りかわる（日本語以外は英語）。タイトルのボタンや `?lang=en` / `?lang=ja` でも切りかえられる。文言は `L("日本語", "English")` とその場に並べて書く（`src/i18n.ts`）。
