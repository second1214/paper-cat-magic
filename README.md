# paper-cat-magic

ママは虫が大の苦手。おうちに入りこんだ虫を、猫がおもちゃで追い払う見下ろし型アクション（ブラウザ / three.js）。

## 遊び方

| 操作 | PC | スマホ（横持ち推奨） |
|---|---|---|
| 移動 | WASD / 矢印キー | 画面をドラッグ（触った所が中心のスティック） |
| 攻撃 | クリック長押し（マウスの方向）／ J（近くの虫を自動で狙う） | 右下の「攻撃」を押しっぱなし（近くの虫を自動で狙う） |
| よける | Space（一瞬むてき） | 「ダッシュ」 |
| おもちゃの編集 | Tab / E / 右上の「おもちゃ」 | 「おもちゃ」 |

春→夏→秋→冬の4季節。各季節はお庭・リビング・寝室・書斎・和室・洋室から選ばれた4部屋（形も家具も毎回変わる）＋スズメバチのボス部屋。
部屋の虫を全部追い払うと扉が開きます。扉の上の絵が**次の部屋をクリアしたときのごほうび**（Magicraft 式の分岐）：

| 絵 | ごほうび |
|---|---|
| ♥ | 最大HP アップ |
| ⚡ | やる気（MP）の最大値・回復アップ |
| ★ | 技・修飾を3つから1つ選ぶ |
| おもちゃ | おもちゃを持ち替える |

## おもちゃと技のしくみ

猫がおもちゃを振ると、スロットにはめた**技（爪・牙・毛玉・シャー）そのものが飛んでいきます**。
おもちゃのスロットは**左から順に**使われ、最後まで使うと少し休けいします。

- **技**（赤い実線の枠）：ひっかき・かみつき・毛玉（範囲）・シャー（すくませて遅くする）
- **修飾**（青い点線の枠＋▶）：▶の向き＝**右隣の技**にかかる。またたび（強化）・じーっ（追尾）・ぽよん（反射）・ぐいぐい（貫通）・二刀流（右の2つを同時に）・つづけて（当たった所からさらに右の技）
- スロットの下の線が「1回で一緒に出るまとまり」。⚔はその合計攻撃力、⚡は使うやる気。次に出るまとまりが光ります。
- 技・おもちゃは Magicraft の説明欄のように、攻撃力・やる気・弾の速さ・とどく距離などの数値つきカードで表示されます。

| おもちゃ | 特徴 |
|---|---|
| ねこじゃらし | 6スロット。ふつう |
| トンボじゃらし | 4スロット。トンボが少し虫を追いかける。休けいが短い |
| ティッシュボール | 8スロット。壁で1回はね返る。休けいが長い |

## 開発

```sh
npm install
npm run dev     # 開発サーバー（同じ Wi-Fi のスマホからも開ける）
npm test        # 発射ロジック・部屋の形・自動プレイ（全季節を通しで詰まないか）のテスト
npm run build   # dist/ に出力
```

- おもちゃ・技のロジック：`src/core/`（DOM 非依存・テストあり）
- ゲームの状態と更新：`src/game/world.ts`、部屋の形と家具配置：`src/game/stage.ts`（描画に依存しない）
- アイテムの絵（3D と UI で共通）：`src/art/items.ts`
- 描画：`src/render/`（three.js。猫は `public/cat/` の紙人形ステッカー、部屋は `roomBuilder.ts`）
- UI・入力：`src/ui/hud.ts`、`src/input.ts`

`main` に push すると GitHub Pages に自動公開されます。
