# paper-cat-magic

紙人形の猫が、杖に魔法をはめて部屋を進んでいく見下ろし型アクション（ブラウザ / three.js）。

## 遊び方

| 操作 | PC | スマホ |
|---|---|---|
| 移動 | WASD / 矢印キー | 画面左をドラッグ |
| 狙って撃つ | マウスで狙う＋クリック長押し | 画面右をドラッグ（引いた方向へ連射） |
| ダッシュ（無敵あり） | Space / Shift | 画面右を軽くタップ |
| 杖の編集 | Tab / E / 右下の「杖」 | 右下の「杖」 |

部屋の敵を全滅させると魔法を1つもらえ、右の出口が開きます。4部屋の先にボスがいます。

## 杖と魔法のしくみ

杖のスロットを左から順に読み、1回の発射で弾を撃ちます。最後まで読んだら再装填。

- **弾**：火花・火の玉（爆発）・氷の矢（鈍足）・雷撃（貫通）
- **修飾**（次の弾にだけ乗る）：強化・追尾・反射
- **二連**：続く2発を同時に撃つ
- **誘発**：次の弾が当たった所から、その次の弾を撃つ

例：`誘発 → 火花 → 火の玉` は「速い火花が当たった場所で火の玉が爆発する」。

## 開発

```sh
npm install
npm run dev     # 開発サーバー（同じ Wi-Fi のスマホからも開ける）
npm test        # 杖の発射ロジックのテスト
npm run build   # dist/ に出力
```

- 杖・魔法のロジック：`src/core/`（DOM 非依存・テストあり）
- ゲームの状態と更新：`src/game/world.ts`（描画に依存しない）
- 描画：`src/render/`（three.js。猫は `public/cat/` の紙人形ステッカーを状態に応じて差し替え）
- UI・入力：`src/ui/hud.ts`、`src/input.ts`

`main` に push すると GitHub Pages に自動公開されます（リポジトリの Settings → Pages で Source を「GitHub Actions」にしておく）。
