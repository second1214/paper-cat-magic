# My Cat Is So Cute

（リポジトリ名: paper-cat-magic）

ママは虫が大の苦手。おうちに入りこんだ虫を、猫がおもちゃで追い払う見下ろし型アクション（ブラウザ / three.js）。

## 遊び方

| 操作 | PC | スマホ（横持ち推奨） |
|---|---|---|
| 移動 | WASD / 矢印キー | 画面をドラッグ（触った所が中心のスティック） |
| 攻撃 | クリック長押し（マウスの方向）／ J（近くの虫を自動で狙う） | 右下の「攻撃」を押しっぱなし（近くの虫を自動で狙う） |
| よける | Space（一瞬むてき） | 「ダッシュ」 |
| おもちゃの編集 | Tab / E / 右上の「おもちゃ」 | 「おもちゃ」 |
| 一時停止 | Esc / P / 右上の「Ⅱ」 | 「Ⅱ」 |

タイトル画面から「はじめる／あそびかた／ずかん（全部の技・おもちゃの説明）」を選べます。いちばん遠くまで進んだ部屋と、守りきった回数はブラウザに記録されます。

秋→冬→春→夏の4季節（虫が一番多い夏が最終章）。各季節はお庭・リビング・寝室・書斎・和室・洋室から選ばれた4部屋（形も家具も毎回変わる）＋スズメバチのボス部屋。
部屋の虫を全部追い払うと扉が開きます。扉の上の絵が**次の部屋をクリアしたときのごほうび**（Magicraft 式の分岐）：

| 絵 | ごほうび |
|---|---|
| ♥ | 最大HP アップ |
| ⚡ | やる気（MP）の最大値・回復アップ |
| ★ | 技・修飾を3つから1つ選ぶ |
| おもちゃ | おもちゃを1つ増やす（3つまで。いっぱいなら今のものと交換） |
| ◆ | レリック（持っているだけで効く）を選ぶ。ボスを倒したときも |
| 帽子 | 装備（帽子・服・首輪）を選ぶ |
| 🎁 宝箱の部屋 | 虫なし。レリック・レア以上の装備・エピック以上の技から1つ |
| 🛋 ママのおひざ | 虫なし。♥ぜんぶ回復 |
| 🐾 秘密の隠し場所 | 虫なし。ソファの下の隠し場所を何回でも使える |
| ‼ 強い虫の部屋 | 強い虫が半分。カリカリの山＋レリック |
| ☁ あやしい箱 | 呪いを1つ受けると、強いごほうび（レリック／伝説の装備／伝説の技）＋カリカリ |

## おもちゃと技のしくみ

猫がおもちゃを振ると、スロットにはめた**技そのもの**が出ます。技ごとに動きが違います。

| 動き | 技 |
|---|---|
| 飛ぶ | ひっかき・かみつき・毛玉（範囲）・シャー（すくませる） |
| まわりを回る | ぶんぶん（ねこじゃらしの先が猫のまわりを回る） |
| ビーム | 毛糸玉ころがし（のびた糸で何度もこする）・レーザーポインター（一瞬で壁まで） |
| 衝撃波 | ねこジャンプ（着地の輪で虫をはじく） |
| 近くを連打 | 猫パンチ連打 |
| 床に置く | 爪とぎ（上を通る虫を削る・4つまで） |
| 召喚 | 友達猫（虫を追いかけてひっかく）・ルンバ（走り回って虫を吸いこむ）。Magicraft と同じく、左の修飾・属性は仲間の攻撃にかかる。召喚ごとに呼べる数（友達猫2・ルンバ1）があり、超えて呼ぶと一番古い仲間が帰る |
おもちゃのスロットは**左から順に**使われ、最後まで使うと少し休けいします。

- **技**（赤い実線の枠）：ひっかき・かみつき・毛玉（範囲）・シャー（すくませて遅くする）
- **修飾**（青い点線の枠）：矢印の向きでかかる技が決まる（Magicraft の右・左・両側・全体修飾）。
  - ▶ **右の技**：またたび（強化）・かじかじ（多段）・でっかく・ちっちゃく（豆つぶで高威力）・すばやく・じーっ（追尾）・ぽよん（反射）・ぐいぐい（貫通）・二刀流（右の2つを同時に）ほか
  - ◀ **左の技**：おかわり（＋1回当たる）・おいかけっこ（追尾）・つるつるの床（はね返り＋遠くまで）
  - ◀▶ **左右の技**（2つをいっしょに出す）：ドライヤー・またたび袋・こたつ布団
  - **全** 全体修飾（どこに置いても全部の技に。読まれず、やる気の最大が減る）：迷子札・ひだまり・人感センサーライト・毛づくろい
- **つづけて**：`[ひっかき][つづけて][ぶんぶん]` ＝ ひっかきが当たった所を中心にぶんぶんが回る（何段でもつながる）。**ひと呼吸**は当たらなくても0.45秒後にその場所から。
- **ふたつ持ち**：`[A][ふたつ持ち][B]` ＝ 前足でおもちゃを2つ同時に扱い、A と B を1つの技にまとめて出す（攻撃力・多段・貫通・はね返り・範囲・属性を足す）。
- **レア度**：技は ふつう／レア／エピック／伝説（マスの下の帯）。**秘密の隠し場所**（ソファの下・ママのところにもある）に同じレア度の物を4つ押しこむと、奥から前に失くした1つ上のレア度の物がランダムで1つ出てくる。
- **属性**（おうちのもの）：静電気＝ビリビリ（近くの虫へ飛び移る）・水のみ皿＝びしょぬれ（遅くなる）・ガムテープ＝ねばねば（足止め）・虫よけスプレー＝虫よけ（じわじわダメージ）。**ぬれた虫にビリビリは2倍**、**ねばねばの虫に虫よけは2倍**
- スロットの下の線が「1回で一緒に出るまとまり」。⚔はその合計攻撃力、⚡は使うやる気。次に出るまとまりが光ります。
- 技・おもちゃは Magicraft の説明欄のように、攻撃力・やる気・弾の速さ・とどく距離などの数値つきカードで表示されます。

| おもちゃ | 特徴 |
|---|---|
| ねこじゃらし | 6スロット。ふつう |
| トンボじゃらし | 4スロット。トンボが少し虫を追いかける。休けいが短い |
| ティッシュボール | 8スロット。壁で1回はね返る。休けいが長い |
| けりぐるみ | 3スロット。攻撃力×1.35、振るのが遅い |
| ピンポン玉 | 5スロット。速く、2回はね返る |
| ただのひも | 10スロット。休けいが長い |
| ペットボトルのキャップ | 3スロット。やる気の回復がとても速く休けいが短い |
| ロングじゃらし | 6スロット。1.4倍遠くまで届き、少し大きい |
| 鈴入りボール | 全部のスロットを1回でいっぺんに出す |
| 紙袋 | サブスロット2：1.5秒じっとすると発動 |
| 猫トンネル | サブスロット2：2回ダッシュで発動 |
| ねずみのぬいぐるみ | サブスロット3：技を14回当てると発動。かみつき入り |
| またたびの木 | サブスロット2：虫を4匹たおすと発動 |
| 知育ボール | サブスロット3：ダメージを受けると発動（反撃） |

- **サブスロット**（Magicraft の副スロット）：条件がたまると、やる気を使わずに全部いっぺんに出る。
- **電池式のおもちゃ**（持ち替えの3つとは別に2つまで）：持っているだけで、一番近い虫へ自動で振る。電動ねずみ・自動レーザー・ぴちぴち魚（USB充電の動く魚）・電動くるくるじゃらし。中の技は入れ替えられる。

## レリックと装備（Magicraft のレリック・装備セット）

- **おもちゃは3つまで持てる**（Magicraft の杖と同じく、やる気と次のスロットはおもちゃごと）。持ち替えはスロットの左の小さなおもちゃ／Q／1〜3／ホイール。
- **レリック**（14種）：最大HP・攻撃力・やる気回復・移動の速さ・召喚の上限・ごほうびの選択肢など。同じものは二度出ない。
- **装備**（4セット×頭・服・首）：飼い主が「かわいい！」と買ってきた、よくわからない物を着せられている。1つずつの効果に加え、同じセットを2つ・3つそろえるとボーナス。
  - ハワイのお土産（ハイビスカスの髪飾り・アロハシャツ・フラのレイ）：やる気回復、3つで止まっていると回復2倍
  - ガチャガチャの天使（天使の輪カチューシャ・天使の羽・光るハートの首輪）：当たりを防ぐ、3つで部屋を片付けると♥1回復
  - くだものの被り物（みかんの被り物・スイカ柄のTシャツ・さくらんぼの首輪）：最大HP、3つで当たったあとのむてき＋0.5秒
  - ママの手編み（毛糸の帽子・手編みのセーター・迷子札の首輪）：攻撃力、3つでダッシュのあと攻撃力1.5倍
- **買ってきた物の技・修飾**（12種）：水鉄砲（びしょぬれ）・ゴムのアヒル（はね返る）・シャボン玉（漂って追いかける）・ハロウィンのかぼちゃ（大きくはじける）・粘着コロコロ（線の上の虫がくっつく）・ピコピコハンマー・自撮りフラッシュ（まわりをすくませる）・通販の段ボール（床に置く）／ラメのシール・鈴のリボン・よくわからない健康グッズ・自撮り棒
- 「持ち物」画面のタブで、おもちゃごとのスロットと、装備・レリックを確認できます。

## ステージ・お店・さいご

- 部屋は 28×16 マスに広くなり、カメラが猫を追う。各季節は8部屋＋ボス（章の真ん中に必ずお店の扉、ときどき特別な部屋の扉）。部屋は お庭／池のあるお庭／家庭菜園（外）、リビング・寝室・書斎・和室・洋室・キッチン・お風呂場・玄関（家の中）。毎章どこかで外を通る。
- 虫を倒すと **カリカリ**（お金）が落ちる。👩の扉の先は **ママのところ**（Magicraft のお店にあたる。拾ったカリカリと交換で技やおやつをおねだり・「ほかのも見せて」〔だんだん高くなる〕・売ることはできない）。**ママのお直し** では、同じ物3つをママが縫い合わせて丈夫な★の物1つにしてくれる（★★まで）。
- **子どもたち**：まれにリビングへ、お兄ちゃん（6さい）と妹（3さい）が遊びに来る。猫と遊びたくて部屋じゅう追いかけてくるが、猫は必死に逃げる（そばに来ると少し速く走る）。攻撃は効かない（当たらない）。つかまると数秒だっこでもみくちゃにされて動けず♥が減る（ダッシュでじたばたすると早く抜け出せる）。逃げられた子は少し息をととのえて、また追いかけてくる。部屋を片付けるとママに呼ばれて帰る。絵は `public/kids/{boy,girl}_{walk,hug}.png` を置くと差し替わる（ないときは仮の絵）。
- 夏のボスを倒すと、さいごは **ママ**。猫を病院へ連れて行こうとニコニコ近づいてくる。猫は肉球ペシペシしかできず（たたくと少し止まる）、ママは倒せない。つかまったらクリア。
- 音楽と効果音（季節・ボス・お店・ママで曲が変わる）。右上の ♪ で消せる。

## 強い虫と呪い

- **強い虫**：足元が光る大きな虫。体力3倍（かたいは4.5倍）、カリカリを多く落とす。性質は すばしこい／分かれる（倒すと2匹に）／はじける（倒すと輪の弾）／かたい。季節・部屋が進むほど出やすい。
- **呪い**（あやしい箱で受ける・その冒険のあいだずっと）：虫がかたい／虫がせっかち／強い虫がよく出る／虫の群れ／お店の値上げ／ねむい／かぜぎみ。呪い1つにつき、もらえるにぼし＋15%。

## 解放（負けても積み上がる）

倒した虫・強い虫・ボス・片付けた部屋・特別な部屋・呪い・進んだ季節・クリアの**合計**で、新しいおもちゃ（15種）・技（12種）・レリック（4種）が解放され、次の冒険から出てくる。途中の季節で負けても記録は積み上がる。結果画面に「新しく解放！」、ずかんに解放の条件が出る。

## 装備のレアリティ・難易度・ねこの成長

- 装備は **ふつう／レア／エピック／伝説**。上がるほど効果が大きく、エピックは1つ・伝説は2つの特殊効果（会心・倒して回復・倒すとはじける・反撃・バリア・もう1発・走ってやる気）がつく。セットは6種（100円ショップ・ペットショップの新作を追加）。
- レリックにも Magicraft の特殊効果を持つもの（きらきらビー玉・ハムスターの回し車・防犯ブザー・ペットのお守り・高級猫缶・ママのコピー用紙）を追加。
- **難易度**：やさしい／ふつう／むずかしい／悪夢（むずかしいを守りきると選べる。当たると♥1減る）。
- **ねこの成長**：冒険でもらう「にぼし」（片付けた部屋・倒したボス・クリア×難易度）で、最大HP・攻撃力・やる気・速さ・レア装備の出やすさ・最初からレリックを永続強化。ブラウザに保存。

## 開発

```sh
npm install
npm run dev     # 開発サーバー（同じ Wi-Fi のスマホからも開ける）
npm test        # 発射ロジック・技の動きと属性・部屋の形・自動プレイ（全季節を通しで詰まないか）のテスト
npm run build   # dist/ に出力
```

- おもちゃ・技のロジック：`src/core/`（DOM 非依存・テストあり）
- ゲームの状態と更新：`src/game/world.ts`、部屋の形と家具配置：`src/game/stage.ts`（描画に依存しない）
- アイテムの絵（3D と UI で共通）：`src/art/items.ts`
- 描画：`src/render/`（three.js。猫は `public/cat/` の紙人形ステッカー、部屋は `roomBuilder.ts`）
- UI・入力：`src/ui/hud.ts`、`src/input.ts`

`main` に push すると GitHub Pages に自動公開されます。
